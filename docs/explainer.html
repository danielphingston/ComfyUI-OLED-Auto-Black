Inside OLED Auto Black

An OLED pixel at value 0 is switched off. A pixel at 15 is on, glowing a dim grey that you can see in a dark room. Diffusion models leave a whole sky of those. This page walks through how the node finds that haze, kills it, and keeps the smoke, hair and edges you actually wanted.

1

One number per pixel

Every decision is made on a single brightness value per pixel, v. The obvious choice is luminance. The node uses the brightest channel instead.

v = max(R, G, B) # protect_color = on v = 0.2126R + 0.7152G + 0.0722B # protect_color = off

A deep red like (64, 5, 5) has a luminance of only about 18, which is below the black point, so a luminance test would erase it. Its max channel is 64, clearly a real colour. The swatches on the right run both versions through the same black point.

Your original BlendIf nodes used "gray", which is luminance. That is why dark reds and blues were at risk.

2

Find the haze in the histogram

The node takes every pixel darker than 64 and counts how many sit at each level. On a dark wallpaper the background is most of the image, so it shows up as one tall peak. That peak is the haze level, bg.

The width of the peak is the noise. It is measured with the median absolute deviation, which ignores outliers like the moon or a wisp crossing the window.

hist = histogram(v < 64, 1-level bins) hist' = hist ∗ [1 2 3 2 1] # smooth so one spiky bin can't win bg = argmax(hist') + 0.5 σ = 1.4826 · median(|x − median(x)|), |x − bg| < 12 t0 = clamp(bg + k·σ, 3, max_black_point) t1 = t0 + max(4, 0.6·t0) # end of the fade

The preset picks k: gentle 2, balanced 3, aggressive 5. With Gaussian noise, 3σ above the peak is above 99.8% of the haze pixels, so almost all of it will be cleared while staying as low as possible.

The 1.4826 factor turns the MAD into a standard deviation for normal noise. If fewer than 10% of pixels are dark, the image isn't a dark wallpaper, and the node falls back to a tiny black point of 2.

x axis: value 0–64
3

The tone curve

Below t0 the output is zero. Above t1 the image is untouched. In between, a smoothstep eases in so there is no visible edge where the black begins.

smoothstep(a, b, x) = t²(3 − 2t), t = clamp((x − a)/(b − a), 0, 1) dehaze(x) = max(x − h·(1 − smoothstep(0, 128, x)), 0) # h = bg · shadow_dehaze flat(x) = dehaze(x) · smoothstep(t0, t1, x)

dehaze pulls the subject's own shadows down by up to h. That removes the milky veil the haze also left on the subject. Its effect fades to nothing by mid-grey, so highlights don't move.

4

Telling detail from noise

A faint wisp and a noise spike can have the same value. What differs is the neighbourhood. Flat haze only wobbles by σ. An edge, a hair or a wisp makes the values inside a small window spread much wider.

So the node computes the standard deviation in a small window around every pixel, using two box blurs over an integral image so it costs the same at any window size.

sd = √( mean(v²) − mean(v)² ) # over a (2r+1)² window r = max(1, round(min(H, W) / 600)) struct = smoothstep(1.5σ, 3σ, sd) · detail_protection

The scope shows a 1-D slice through the image: noise, then a wisp, then the moon's edge. The window slides across it. Where the spread climbs past 1.5σ, struct starts turning green.

The radius scales with resolution, so the 2× upscaled image is measured over the same physical area as the original.

5

Two curves, blended per pixel

Structured pixels get a different curve. Instead of the steep smoothstep, the range from just above the haze to t1 is stretched linearly down to zero. A wisp that was 11 levels above the haze ends up about 10 levels above true black. Its contrast survives; only the floor under it moves.

lo = bg + 2.5σ # still haze, even if "structured" detail = max(flat, dehaze(t1) · (v − lo)/(t1 − lo)) # for v < t1 out_v = flat + (detail − flat) · struct

Because struct is a smooth weight from 0 to 1, pixels on the border between noise and detail get a mix of both curves rather than a hard switch.

The lo floor is why there is no halo around the moon. Background pixels next to a sharp edge do have a high spread, but their value is still haze, below lo, so they go to zero anyway.

6

Despeckle: dots go, lines stay

After the curve, a few single pixels of noise survive in the black. The node looks at a 5×5 window around each lit pixel and asks what fraction of it is already black.

black = out_v < 0.5 surround = box_mean(black, 5×5) speck = surround > 0.92 and v < 2·t1 and out_v > 0

A lone dot leaves 24 of 25 cells black, which is 0.96, so it is removed. A 1-pixel line passes through 5 cells, leaving 0.80, so it stays. The v < 2·t1 check keeps real stars: a single pixel that is genuinely bright is never treated as a speck.

7

Apply as one gain, then dither

The curve gave a new brightness out_v for each pixel. To apply it without shifting the colour, all three channels are multiplied by the same factor. A dim blue rim light stays the same blue, just darker.

gain = out_v / v RGB_out = clamp(RGB · gain, 0, 1) RGB_out = 0 where out_v ≤ 0 # exact #000000 dither = (U₁ − U₂) / 255, U ~ uniform(0,1) # triangular only where 0 < out_v < dehaze(t1)

The fade-to-black spans only about a dozen 8-bit levels, so a soft glow can show visible steps once saved. Adding up to one level of triangular noise in that zone breaks the steps into grain your eye averages out. The scope shows the same glow without and with dither, brightened so the steps are visible.

Dither is applied before the final zeroing, so it can never put light back into a pixel that should be off.
